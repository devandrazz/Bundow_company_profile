FROZZY — WEBSITE COMPANY PROFILE

Isi folder:
- index.html : struktur halaman
- style.css  : desain, responsive layout, dan efek Liquid Glass
- script.js  : menu mobile, animasi scroll reveal, dan FAQ interaktif
- images/    : tempat menyimpan foto milik UMKM/kelompok

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka folder frozzy_company_profile di VS Code.
3. Buka index.html atau jalankan dengan ekstensi Live Server.
4. Pastikan internet aktif karena foto ilustrasi dan Google Fonts saat ini dimuat dari internet.
