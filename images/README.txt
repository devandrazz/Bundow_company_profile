FROZZY - FOTO TIM

Cara memasang foto anggota:
1. Buka folder frozzy_company_profile/images.
2. Masukkan foto anggota pertama dan beri nama anggota-1.jpg.
3. Masukkan foto anggota kedua dan beri nama anggota-2.jpg.
4. Masukkan foto anggota ketiga dan beri nama anggota-3.jpg.
5. Gunakan foto JPG/JPEG. Jika foto kamu PNG, ubah ekstensi dan nama file di atribut src pada bagian TIM PENGEMBANG di index.html menjadi .png.
6. Ganti teks [Nama anggota 1], [Nama anggota 2], dan [Nama anggota 3] di index.html dengan nama asli.

Foto akan otomatis dipotong proporsional berbentuk lingkaran. Jika foto belum dipasang, lingkaran nomor 01/02/03 tetap tampil sebagai placeholder.
